# 1b1v Lite

**1b1v** is a FastAsyncWorldEdit (FAWE) addon that brings a unified brush GUI, state persistence across server restarts, and new building tools, patterns, and masks to Minecraft.

- **Download (Modrinth):** https://modrinth.com/project/1b1v-lite
- **Documentation (Wiki):** https://1b1v.github.io/
- **Discord (Support & Feedback):** https://discord.gg/5WmnrBXY9J
- **Demo Video (YouTube):** https://www.youtube.com/@Almarelion

## Requirements

- Paper (or compatible fork), Minecraft 1.20.5+
- FastAsyncWorldEdit (FAWE)
- Java 21+
